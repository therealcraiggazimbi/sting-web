STINGDesign System · v1
Sting Runner

Editorial clarity for a premium AI platform. Quiet confidence over decoration — razor-thin lines, disciplined rhythm, one deep-indigo signal, and generous whitespace.

01Look & Feel

Vercel/Linear-grade minimalism

The system reads like a well-set document, not a marketing page. Structure comes from hairline borders and soft neutral fills — never shadows or gradients. Colour is rationed: the interface is almost entirely ink-on-paper, with a single deep indigo reserved for the things that matter (a CTA, an active state, the one card you want the eye to land on). Motion is sharp and brief. Numbers, codes and labels are set in monospace to add a technical, precise texture against the humanist sans.

✓ Hairline borders (0.5px) ✓ Flat surfaces + tint for depth ✓ One indigo signal per view ✓ Mono numerals & labels ✓ Generous whitespace
✕ Drop shadows / glows ✕ Gradients ✕ Multiple accent colours ✕ Rounded-bubbly / playful UI ✕ Dense, cramped layouts
